# 辽宁城市扩展目录

本目录用于辽宁省（不含沈阳、大连）的城市选址能力扩展。

## 实施原则

- 北京 Excel 数据属于特例，不作为辽宁城市实现模板。
- 辽宁城市统一参考惠州模式：以 OpenStreetMap / Overpass 公共 POI 为基础，按行政边界动态分析。
- 当前仅启用鞍山作为试点城市；其他城市先建立目录，待鞍山链路验证后逐城启用。
- 每次启用新城市前保留可回滚提交或备份分支。
